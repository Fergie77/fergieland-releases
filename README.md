# Fergieland releases

The Fire TV versions of **The Pictures** and **The Listings**, ready to install.

- Each app checks `the-pictures.json` or `the-listings.json` here when it opens and offers any newer version.
- The installable files are under [Releases](https://github.com/Fergie77/fergieland-releases/releases).

## First install on a Fire TV

1. Settings › My Fire TV › Developer options: turn on **Apps from Unknown Sources** (or allow the Downloader app).
2. Install **Downloader** from the Amazon Appstore and open this address in it:
   - The Pictures: `https://github.com/Fergie77/fergieland-releases/releases/latest`
   - Pick the `.apk` for the app you want.
3. Open the app. From then on it updates itself: when a new version is out it asks, and **Update** installs it.
